# B 站学习视频推荐系统

本项目通过爬取 B 站视频元数据、UP 主信息、弹幕和评论，对学习视频进行文本分析、情感分析和评论质量评估，最终为用户提供更可靠的学习视频推荐。

系统第一阶段采用本地 Web 部署，支持用户注册登录、学习方向识别、视频推荐、搜索历史和收藏功能。

## 快速了解

```text
用户登录 -> 输入关键词或标签
         -> 识别学习方向
         -> 高置信直接推荐 / 中低置信交互确认
         -> 在目标大类下按综合评分排序
         -> 返回推荐结果
```

视频综合评分由语义相似度、基础热度、弹幕情感和评论质量四部分加权得到。
