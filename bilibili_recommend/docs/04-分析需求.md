# 04 文本分析需求

## 4.1 弹幕情感分析

### 4.1.1 分析目标

将有效弹幕分为积极、消极、中性三类。

### 4.1.2 实现方式

第一阶段采用本地中文情感分析方案：

- 优先使用中文预训练情感模型。
- 备选使用 SnowNLP 等轻量情感分析库。

### 4.1.3 视频情感指标

```text
正面弹幕率 = 正面弹幕数 / 有效弹幕数
负面弹幕率 = 负面弹幕数 / 有效弹幕数
情感得分   = 正面弹幕率 - 负面弹幕率
```

情感得分范围约为 `-1` 到 `1`。

## 4.2 评论质量分析

### 4.2.1 高质量评论标准

高质量评论至少满足以下部分条件：

- 包含具体知识点或解释。
- 针对视频内容提出有效问题。
- 不是刷屏、广告或纯情绪发泄。

### 4.2.2 单条评论质量分

```text
单条评论质量分 =
    0.30 * 文本长度得分
  + 0.20 * 点赞数得分
  + 0.25 * 信息含量得分
  + 0.15 * 有效提问得分
  - 0.10 * 垃圾内容惩罚
```

### 4.2.3 视频评论质量得分

```text
评论质量得分 = 高质量评论数 / 有效评论总数
```

## 4.3 标签一致度风险

由于系统不分析视频画面，无法直接确认视频真实内容。系统可以计算：

```text
标签一致度 = 标签关键词与高频评论词的语义重合度
```

当标签一致度明显偏低时，降低该视频推荐权重，并在结果中提示可能存在的文不对题风险。
