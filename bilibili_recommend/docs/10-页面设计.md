# 10 页面设计

本项目采用 Web 单页应用布局，由顶部栏、左侧栏和主内容区组成，不同功能以路由视图呈现。

## 10.1 全局布局

```text
┌──────────────────────────────────────────────────────────┐
│ Logo      [搜索框]                    登录 / 用户信息      │
├──────────────┬───────────────────────────────────────────┤
│              │                                           │
│ 左侧分类栏   │          主内容区                          │
│              │                                           │
│ 编程开发      │   首页、推荐结果、视频详情、               │
│ 人工智能      │   视频分析、分类列表等                     │
│ ...          │                                           │
│ 其他学习      │                                           │
└──────────────┴───────────────────────────────────────────┘
```

- 顶部搜索框常驻，用户可随时搜索。
- 左侧栏展示 15 个学习方向和一个其他学习。
- 主内容区根据路由切换视图。

## 10.2 首页视图

**路由：`/`**

功能：

- 主内容区展示欢迎语。
- 未搜索时展示热门学习视频。
- 顶部搜索框可输入关键词。
- 左侧栏可点击分类。
- 右上角可登录或进入用户区域。

存在原因：

作为 Web 应用入口，让用户第一眼知道可以搜索或浏览分类。

用户操作和跳转：

```text
顶部搜索 → /recommend
点击左侧分类 → /category/{id}
点击登录 → /login
点击用户名 → /user
点击推荐视频 → /video/{bvid}
```

## 10.3 分类确认弹窗

不是独立页面，而是搜索后无法确定学习方向时出现的弹窗。

触发条件：

```text
高置信：不出现弹窗，直接进入 /recommend
中置信：展示候选分类
低置信：展示其他学习、重新输入和候选分类
```

用户操作和跳转：

```text
选择候选分类 → /recommend，并带上分类参数
点击其他学习 → /recommend，不限制分类
点击重新输入 → 返回搜索框
```

## 10.4 推荐结果视图

**路由：`/recommend`**

功能：

- 展示识别出的学习方向。
- 展示推荐视频列表。
- 展示视频标题、UP 主、封面、标签和综合评分。
- 提供权重与筛选弹窗入口。
- 提供收藏按钮。

用户操作和跳转：

```text
点击视频 → /video/{bvid}
点击权重与筛选 → 打开弹窗，应用后刷新当前页
点击收藏 → 收藏状态变化
点击 UP 主 → /up/{mid}
```

## 10.5 权重与筛选弹窗

在推荐结果页通过“筛选 / 权重”按钮打开。

内容：

```text
语义相似度权重
基础热度权重
弹幕情感权重
评论质量权重
恢复默认按钮
可选时长、排序、UP 主粉丝量筛选
```

点击应用后重新请求 `/api/recommend` 并刷新推荐结果。

## 10.6 视频详情视图

**路由：`/video/{bvid}`**

功能：

- 展示视频标题、简介、封面、UP 主、分区、标签。
- 展示播放量、点赞、收藏等基础数据。
- 提供“查看分析”入口。
- 提供跳转 B 站原视频链接。
- 提供收藏按钮。

用户操作和跳转：

```text
点击查看分析 → /video/{bvid}/analysis
点击 UP 主 → /up/{mid}
点击返回 → /recommend
```

## 10.7 视频分析视图

**路由：`/video/{bvid}/analysis`**

功能：

- 展示弹幕情感分布。
- 展示弹幕密度变化。
- 展示评论质量分布。
- 展示字幕和评论高频关键词。
- 展示标签一致度风险。

用户操作和跳转：

```text
返回视频详情 → /video/{bvid}
返回推荐列表 → /recommend
```

## 10.8 分类浏览视图

**路由：`/category`**

提示：该视图可取消。左侧栏已经展示全部分类，重复保留分类浏览页会造成信息重复。

如果保留，功能是展示所有学习方向分类的卡片或列表，点击某个分类后进入该分类的视频列表。

取消后的分类浏览由左侧栏完成：

```text
点击左侧分类 → /category/{id}
```

## 10.9 分类视频列表视图

**路由：`/category/{id}`**

功能：

- 展示某个学习方向下的视频列表。
- 支持分页。
- 展示视频标题、UP 主、封面和评分。

用户操作和跳转：

```text
点击视频 → /video/{bvid}
点击下一页 → 刷新当前页
点击 UP 主 → /up/{mid}
```

## 10.10 UP 主视频列表视图

**路由：`/up/{mid}`**

功能：

- 展示 UP 主基本信息和视频列表。

用户操作和跳转：

```text
点击视频 → /video/{bvid}
返回 → 推荐结果或分类列表
```

## 10.11 登录注册页

**路由：`/login`、`/register`**

功能：

- 登录：输入用户名、密码。
- 注册：创建账号。

登录或注册成功后跳转到 `/`。

## 10.12 个人中心视图

**路由：`/user`、`/user/favorites`、`/user/history`**

功能：

- 查看收藏列表。
- 查看搜索历史。
- 查看和修改基本信息。

用户操作和跳转：

```text
点击收藏视频 → /video/{bvid}
点击搜索历史 → /recommend 并重新推荐
返回首页 → /
```

## 10.13 路由汇总

```text
/                          首页
/recommend                 推荐结果
/category/{id}             分类视频列表
/video/{bvid}              视频详情
/video/{bvid}/analysis     视频分析
/up/{mid}                  UP 主视频列表
/login                     登录
/register                  注册
/user                      个人中心
/user/favorites            收藏列表
/user/history              搜索历史
```
