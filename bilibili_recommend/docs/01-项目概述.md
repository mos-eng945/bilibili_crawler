# 01 项目概述

## 1.1 项目背景

B 站视频数量庞大，学习类视频尤其存在以下问题：

- 视频标题和实际内容不完全一致。
- 标题、标签写得很好，但教学质量和信息密度参差不齐。
- 用户很难快速判断一个视频是否真正符合自己的学习需求。

因此，本项目通过爬取 B 站视频元数据、UP 主信息、弹幕和评论，综合进行文本分析与质量评估，为用户提供更可靠的学习视频推荐。

## 1.2 项目目标

建设一个本地运行的 Web 系统，实现以下闭环：

```text
爬取数据 -> 数据存储 -> 数据清洗与分析 -> 学习方向识别 -> 视频推荐 -> 结果展示
```

项目实施遵循“先跑通最小数据闭环，再逐步加功能”的原则：先完成数据爬取与入库，验证字段和反爬情况，再进入清洗、分析和推荐模块开发。不建议完全按“全部爬完、再整理、再处理”串行推进，否则容易在最后才发现字段不对、数据量太大或爬虫策略有问题。

## 1.3 术语定义

| 术语 | 说明 |
| --- | --- |
| UP 主 | B 站视频上传者 |
| 弹幕 | 视频播放时显示的用户即时评论 |
| 学习方向 | 系统定义的学习视频大类，例如编程开发、美食烹饪 |
| 情感分析 | 判断弹幕或评论的情绪倾向，分为积极、消极、中性 |
| 评论质量 | 评论是否包含有效信息、是否针对视频内容 |
| 置信度 | 系统判断用户输入所属学习方向的确定程度 |

## 1.4 项目范围

### 1.4.1 本项目包含

- B 站视频元数据、UP 主信息、弹幕、评论的数据爬取。
- 数据清洗、中文文本处理和存储。
- 弹幕情感分析。
- 评论质量评估。
- 用户注册、登录、登出。
- 用户输入关键词或标签后，识别学习方向。
- 基于学习方向、情感和评论质量的视频推荐。
- 搜索历史、收藏功能。
- 推荐结果和视频数据的 Web 展示。

### 1.4.2 本项目不包含

- 视频字幕提取、音频转写、画面 OCR、视频分帧等视频内容理解。
- 复杂的多用户个性化推荐算法。
- 移动端 App。
- 公网生产环境部署和运维。

### 1.4.3 范围说明

本项目不直接判断“视频真实内容和标题是否一致”，因为仅凭标题、弹幕和评论无法可靠得到视频真实内容。系统通过多来源文本推断学习方向，并将标签与评论的高频词差异作为“文不对题风险”的辅助信号。
