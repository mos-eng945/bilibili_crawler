# 06 非功能需求

## 6.1 部署要求

- 第一阶段在本地单机运行。
- 使用本地浏览器访问。
- 无需购买或部署云服务器。
- 系统结构预留云服务器部署能力。

## 6.2 性能要求

- 普通页面加载和推荐响应应在可接受时间内完成。
- 建议单次推荐响应时间不超过 2 秒。
- 数据量较大时可采用预处理和索引优化。

## 6.3 安全要求

- 用户密码必须哈希存储，不保存明文密码。
- 使用会话管理登录状态。
- 注意防止 SQL 注入、XSS、CSRF 等常见 Web 安全问题。

## 6.4 合规要求

- 控制爬取频率，降低对目标平台的压力。
- 仅用于学习研究，不进行大规模商业采集。
- 遵守 B 站相关协议和法律法规。
- 不采集和展示用户敏感隐私信息。

## 6.5 可维护性

- 分类、权重等参数尽量配置化。
- 爬虫、分析、推荐模块尽量解耦。
- 关键模块添加必要的日志和错误处理。
