# 12 数据与实现说明

本文记录爬虫输出文件的真实格式、字段映射和已落地的实现脚本，便于后续开发和维护。

## 12.1 爬虫输出目录结构

```text
output/
├── search/
│   └── <关键词>/
│       └── search_<时间>_<数量>.csv
├── up/
│   └── <mid+UP主名称>/
│       └── videos_<时间>_<数量>.csv
└── video/
    └── <BV号_UP主名称>/
        ├── video_info.json
        ├── danmaku_<标题>.csv
        ├── comments_<BV号>.csv
        └── subtitle_<BV号>_p<N>_ai-zh.json / .srt
```

## 12.2 各文件实际字段

### 12.2.1 search CSV 和 up CSV

```text
bvid, title, published_at, author, mid, partition, tags,
duration_seconds, cover_url, like, comment_count, favorite_count,
share_count, author_follower_count, play_count, danmaku_count
```

其中 `up` 目录的视频 CSV 多出 `share_count`，`search` 目录的部分文件可能没有该字段。

### 12.2.2 video_info.json

主要字段：

```text
bvid, aid, mid, title, description, cover_url,
published_at, created_at, duration_seconds, videos,
tid, partition, up_name, up_face, up_follower_count,
view, like, coin, favorite, reply, share, danmaku, pages
```

`pages` 中每个分 P 包含：

```text
page, cid, part, duration
```

### 12.2.3 弹幕 CSV

中文表头：

```text
弹幕id, 出现时间, 权重, 内容, 哈希, 发送时间, 弹幕池
```

其中“出现时间”格式为 `HH:MM:SS`。

### 12.2.4 评论 CSV

```text
rpid, mid, user_name, user_level, sex, vip, message,
ctime_text, like, reply_count, state, ip_location, image_urls
```

### 12.2.5 AI 字幕 JSON

```text
bvid, cid, page, part, language
subtitle.body[].from, .to, .content
```

每条字幕包含开始时间、结束时间和文本。

## 12.3 字段名映射

`search CSV / up CSV` 与 `video_info.json` 对同一含义使用不同字段名，入库时需要统一：

| 含义 | search / up CSV | video_info.json |
| --- | --- | --- |
| 作者 | author | up_name |
| 点赞数 | like | like |
| 评论数 | comment_count | reply |
| 收藏数 | favorite_count | favorite |
| 播放量 | play_count | view |
| 弹幕数 | danmaku_count | danmaku |
| 粉丝数 | author_follower_count | up_follower_count |
| 分区 | partition | partition |
| 时长 | duration_seconds | duration_seconds |
| 封面 | cover_url | cover_url |

## 12.5 数据清洗实现

位置：

```text
C:\course\data\bilibili_recommend\database\data_cleaning.py
```

作用：

```text
从 danmaku 清洗出 danmaku_clean
从 comments 清洗出 comments_clean
```

清洗规则：

```text
去除空白文本
去除无中文、字母、数字的内容
去除广告、链接、加群、兼职等垃圾内容
统一空白字符
弹幕按同一视频内重复内容去重
评论按同一用户重复内容去重
```

运行：

```powershell
cd C:\course\data\bilibili_recommend\database
python data_cleaning.py
```

## 12.6 全库分析实现

位置：

```text
C:\course\data\bilibili_recommend\analysis\database_analysis.py
```

作用：


`video_scores` 表字段：

```text
bvid
popularity
sentiment
comment_quality
danmaku_count
comment_count
subtitle_count
keywords
category_hint
```

## 12.7 配置文件

```text
C:\course\data\bilibili_recommend\config\categories.yaml
C:\course\data\bilibili_recommend\config\recommend.yaml
```

`categories.yaml` 包含 15 个学习方向和“其他学习”兜底类。

`recommend.yaml` 定义默认推荐权重：

```yaml
weights:
  semantic_similarity: 0.3
  popularity: 0.1
  sentiment: 0.3
  comment_quality: 0.3
```

相似度方案为 TF-IDF，权重可由用户按需覆盖。
