# 03 数据需求

## 3.1 数据来源

主要数据来源为 B 站公开可访问的数据接口，包括：

- 视频信息接口。
- UP 主信息接口。
- 弹幕接口。
- 评论接口。

## 3.1.1 数据处理流程

```text
1. 确定数据规模和抓取来源
2. 先小批量试爬，验证字段和接口
3. 爬取原始数据
4. 原始数据先入库
5. 清洗、结构化
6. 分析加工
7. 提供给推荐模块
```

## 3.1.2 数据处理关键点

- 先爬几十到几百个视频验证字段、格式和限流情况，再扩大规模。
- 区分原始数据和清洗后数据，清洗出错时可基于原始数据重新处理。
- 先存原始数据，再用独立清洗任务生成清洗后数据，避免爬虫和清洗逻辑耦合。
- 使用 `bvid` 去重，支持增量更新播放量、点赞数、弹幕和评论。
- 热门视频可能包含数千到数万条弹幕，需要分页抓取并建立索引。
- 爬虫需要限速、随机延迟、失败重试、断点续传和日志记录。

## 3.4 数据清洗

数据清洗包括但不限于：

- 去除重复视频和重复弹幕。
- 去除纯表情、纯符号、无意义字符。
- 去除刷屏弹幕和无意义评论。
- 过滤广告、引流链接等垃圾内容。
- 统一文本编码和日期格式。
