| 美食烹饪 | 美食、做饭、家常菜、烘焙、甜品 |
| 体育运动 | 健身、跑步、篮球、羽毛球、瑜伽 |

其余内容归入“其他学习”兜底大类。

## 5.1 分类配置

大类采用配置文件方式管理，每个大类包含：

- 大类 ID。
- 大类名称。
- 大类描述。
- 关键词列表。
- 对应 B 站分区。

配置示例：

```yaml
- id: cooking
  name: 美食烹饪
  description: 家常菜、烘焙、甜点、饮品等美食制作教学
  keywords:
    - 美食
    - 做饭
    - 家常菜
    - 烘焙
    - 甜品
  bilibili_partitions:
    - 生活区
```

## 5.2 分类体系维护

- 分类配置化，便于增删改。
- 根据爬取数据的分区和标签分布调整类别。
- 数据量过少的类别可合并。
- 低置信度输入可沉淀为新增类别的依据。
