# 15 推荐实现说明

本文记录推荐后端需要的预处理数据和实现方案。

## 15.1 视频文本表

用于推荐时计算 TF-IDF，预先生成一张表。

```text
video_texts
  bvid        视频 ID，主键
  video_text  拼接后的视频文本
  updated_at  更新时间
```

视频文本组成：

```text
标题 + 简介 + 标签 + 字幕关键词
```

好处：

```text
推荐时不需要每次实时拼接多个表
提高查询性能
```

## 15.2 视频分类表

```text
video_categories
  id          主键
  bvid        视频 ID
  category_id 分类 ID
  score       匹配得分
```

用于根据学习方向过滤视频。

## 15.3 分类规则

分类依据：

```text
标题
简介
B 站分区
视频标签
字幕关键词
```

匹配方式：

```text
1. 读取 categories.yaml 的分类关键词和分区
2. 对每个视频拼成分类文本
3. 统计命中的关键词数量
4. 如果分区匹配，额外加分
5. 取得分最高的前 3 个分类
6. 没有匹配的分类，归入 other
```

分类脚本：

```text
C:\course\data\bilibili_recommend\database\build_video_categories.py
```

运行：

```powershell
cd C:\course\data\bilibili_recommend\database
python build_video_categories.py
```

## 15.4 TF-IDF 实现

使用 scikit-learn：

```text
TfidfVectorizer
```

用户输入和视频文本都通过 TF-IDF 向量化，再计算余弦相似度。

## 15.5 缺失分数处理

部分视频没有弹幕或评论，导致：

```text
sentiment 为 NULL
comment_quality 为 NULL
```

推荐计算时按：

```text
0.5 中性处理
```

避免这些视频被不公平淘汰。

## 15.6 当前分类结果

对现有 161 个视频运行分类脚本后：

```text

归入其他学习：145
```

因为当前数据中：

```text

```

## 15.7 数据流水线

新增一个统一脚本，按顺序执行完整流程：

```text
C:\course\data\bilibili_recommend\database\run_pipeline.py
```

执行顺序：

```text
1. 导入爬虫数据
2. 清洗弹幕和评论
3. 全库文本分析
4. 视频分类
```

运行：

```powershell
cd C:\course\data\bilibili_recommend\database
python run_pipeline.py
```

以后每爬一批新数据，只需要运行这个脚本，就会自动完成导入、清洗、分析和分类。
