# 07 技术方案

## 7.1 推荐技术栈

| 模块 | 推荐技术 |
| --- | --- |
| 爬虫 | Python、Requests 或 Scrapy |
| 后端 | FastAPI |
| 登录 | 预留认证模块，第一阶段暂不实现 |
| 数据库 | MySQL |
| 中文分词 | Jieba |
| 情感分析 | SnowNLP 或中文预训练模型 |
| 相似度 | TF-IDF |
| 前端 | HTML + CSS + JavaScript，或 Vue/React |
| 可视化 | ECharts |

## 7.2 目录结构建议

```text
course/
├── data/                 # 数据与文档
├── crawler/              # 爬虫模块
├── analysis/             # 文本分析与评分
├── recommend/            # 分类与推荐
├── web/                  # 后端接口与前端页面
├── config/               # 分类与权重配置
└── db/                   # 数据库文件或初始化脚本
```

## 7.3 已确定配置

| 配置项 | 取值 |
| --- | --- |
| 后端框架 | FastAPI |
| 相似度方案 | TF-IDF |
| 分类配置 | `config/categories.yaml` |
| 推荐权重配置 | `config/recommend.yaml` |
| 默认权重 | 语义相似度 0.3、热度 0.1、情感 0.3、评论质量 0.3 |

推荐权重支持用户通过接口参数覆盖默认值。
