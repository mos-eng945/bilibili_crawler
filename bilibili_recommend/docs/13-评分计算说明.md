# 13 评分计算说明

本文说明分类置信度和推荐综合分是如何从真实数据计算出来的。

## 13.1 分类置信度计算

系统使用“关键词规则 + TF-IDF 相似度”判断用户输入所属的学习方向。

### 13.1.1 关键词规则分

对每个学习方向，统计用户输入命中了多少个该方向的关键词。

```text
命中数量 = 用户输入中出现的分类关键词数量
关键词规则分 = 命中数量 / 该分类关键词总数
```

示例：

```text
用户输入：想学 Python 爬虫
编程开发关键词：Python、Java、前端、后端、爬虫、算法...
命中：Python、爬虫，共 2 个
关键词规则分 = 2 / 15 ≈ 0.133
```

### 13.1.2 TF-IDF 相似度分

将用户输入和分类描述转换为 TF-IDF 向量，计算余弦相似度。

```text
相似度 = cosine(user_vector, category_vector)
```

结果范围为 `0` 到 `1`。

### 13.1.3 分类总分

```text
分类总分 = a * 关键词规则分 + b * TF-IDF 相似度分
```

其中 `a`、`b` 为可配置权重。

### 13.1.4 置信度判断

对所有分类按总分从高到低排序：

```text
score1：第一名分类分数
score2：第二名分类分数
diff = score1 - score2
```

根据配置阈值判断：

```text
diff > 0.25           -> 高置信
score1 >= 0.30        -> 中置信
其他                  -> 低置信
```

当前配置：

```text
high_confidence_diff = 0.25
low_confidence_score = 0.30
```

## 13.2 推荐综合分

```text
最终推荐分 =
    w1 * 语义相似度
  + w2 * 基础热度
  + w3 * 弹幕情感
  + w4 * 评论质量
```

默认权重：

```text
语义相似度 0.3
基础热度 0.1
弹幕情感 0.3
评论质量 0.3
```

## 13.3 四个子分数计算

### 13.3.1 语义相似度

用户输入与视频文本的 TF-IDF 余弦相似度。

视频文本来源：

```text
标题 + 简介 + 标签 + 字幕关键词
```

结果范围为 `0` 到 `1`。

### 13.3.2 基础热度

使用对数缩放和比率归一化：

```text
播放量得分 = min(log10(播放量 + 1) / 8, 1)
点赞率得分 = min(点赞数 / 播放量 * 20, 1)
收藏率得分 = min(收藏数 / 播放量 * 10, 1)
弹幕活跃得分 = min(log10(弹幕数 + 1) / 6, 1)

基础热度 = 0.4 * 播放量得分
         + 0.25 * 点赞率得分
         + 0.20 * 收藏率得分
         + 0.15 * 弹幕活跃得分
```

结果范围为 `0` 到 `1`。

### 13.3.3 弹幕情感

每条弹幕使用 SnowNLP 得到 `0` 到 `1` 的情感分数：

```text
score >= 0.6 -> 积极
score <= 0.4 -> 消极
其他 -> 中性
```

整个视频：

```text
正面率 = 正面弹幕数 / 总弹幕数
负面率 = 负面弹幕数 / 总弹幕数
情感得分 = 正面率 - 负面率
```

推荐时归一化：

```text
情感归一化 = (情感得分 + 1) / 2
```

### 13.3.4 评论质量

单条评论规则打分：

```text
单条评论质量 =
    0.30 * 长度得分
  + 0.20 * 点赞得分
  + 0.25 * 信息含量
  + 0.15 * 是否提问
  - 0.10 * 垃圾惩罚
```

视频评论质量：

```text
评论质量 = 所有评论质量分的平均值
```

结果范围为 `0` 到 `1`。

## 13.4 计算示例

某个视频：

```text
语义相似度 = 0.32
基础热度 = 0.71
弹幕情感 = 0.55
评论质量 = 0.61
```

最终推荐分：

```text
0.3 * 0.32 + 0.1 * 0.71 + 0.3 * 0.55 + 0.3 * 0.61
= 0.096 + 0.071 + 0.165 + 0.183
= 0.515
```

## 13.5 方法说明

| 分数 | 方法 |
| --- | --- |
| 关键词规则分 | 规则匹配 |
| TF-IDF 相似度 | 传统文本统计方法 |
| 基础热度 | 数学公式归一化 |
| 评论质量 | 规则特征打分 |
| 弹幕情感 | SnowNLP 轻量统计分类模型 |

整体采用规则、传统文本方法和数学归一化，不需要训练自定义深度学习模型。
