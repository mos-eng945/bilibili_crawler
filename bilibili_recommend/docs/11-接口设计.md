# 11 接口设计

本文定义后端提供给前端的 HTTP 接口。

## 11.1 通用约定

- 请求和返回均使用 JSON。
- 成功返回 HTTP 状态码 `200`。
- 参数错误返回 `400`。
- 资源不存在返回 `404`。
- 错误返回统一格式：

```json
{
  "detail": "错误说明"
}
```

FastAPI 启动后可访问：

```text
http://127.0.0.1:8000/docs
```

查看自动生成的接口文档。

## 11.1.1 用户数据权限约定

- 用户私有资源接口不接收 `user_id` 参数。
- 当前用户身份由后端登录会话或 Token 确定。
- `favorites`、`search_history`、`feedback` 等数据必须绑定当前登录用户。
- 用户不能通过修改 URL 或请求参数访问其他用户的数据。

## 11.1.2 HTTP 状态码约定

| 状态码 | 含义 | 使用场景 |
| --- | --- | --- |
| 200 | 成功 | 查询成功、操作成功 |
| 201 | 创建成功 | 注册成功、收藏成功 |
| 400 | 请求参数错误 | 参数缺失或格式错误 |
| 401 | 未登录 | 访问需要登录的接口但未登录 |
| 403 | 无权限 | 登录但无权访问该资源 |
| 404 | 资源不存在 | 视频或用户不存在 |
| 409 | 资源冲突 | 用户名已存在、重复收藏 |
| 500 | 服务器错误 | 后端异常 |

前端根据状态码决定跳转或提示。后端返回状态码时必须阻止未授权数据泄露。

## 11.1.3 接口路径分组说明

接口路径中的 `auth` 和 `user` 只是功能分组名称，不是不同服务或数据库。

```text
/api/auth/...  身份认证相关
  注册、登录、登出

/api/user/...  当前用户资源相关
  用户信息、收藏、搜索历史
```

这样分组便于前端根据路径快速判断接口用途。

## 11.1.4 接口总览

| 分组 | 方法 | 接口 | 功能 |
| --- | --- | --- | --- |
| 系统 | GET | `/api/health` | 健康检查 |
| 分类 | GET | `/api/categories` | 获取学习方向列表 |
| 视频 | GET | `/api/videos/hot` | 获取热门学习视频 |
| 推荐 | POST | `/api/recommend` | 输入关键词获取推荐 |
| 视频 | GET | `/api/videos` | 获取分类视频列表 |
| 视频 | GET | `/api/videos/{bvid}` | 获取视频详情 |
| 视频 | GET | `/api/videos/{bvid}/analysis` | 获取视频分析结果 |
| UP 主 | GET | `/api/up/{mid}/videos` | 获取 UP 主视频列表 |
| 反馈 | POST | `/api/videos/{bvid}/feedback` | 提交推荐反馈 |
| auth | POST | `/api/auth/register` | 注册账号 |
| auth | POST | `/api/auth/login` | 登录 |
| auth | POST | `/api/auth/logout` | 登出 |
| user | GET | `/api/user/profile` | 获取当前用户信息 |
| user | PUT | `/api/user/profile` | 修改当前用户信息 |
| user | GET | `/api/user/favorites` | 获取收藏列表 |
| user | POST | `/api/user/favorites` | 收藏视频 |
| user | DELETE | `/api/user/favorites/{bvid}` | 取消收藏 |
| user | GET | `/api/user/search_history` | 获取搜索历史 |
| user | DELETE | `/api/user/search_history` | 清空搜索历史 |

分组说明：

```text
系统：服务状态检查
分类：学习方向相关
视频：视频信息和内容
推荐：用户搜索推荐
UP 主：UP 主相关内容
反馈：推荐结果反馈
auth：身份认证
user：当前用户私有资源
```

## 11.2 全局与首页

### 健康检查

```text
GET /api/health
```

### 获取分类列表

```text
GET /api/categories
```

用于左侧栏展示 14 个学习方向和一个其他学习。

### 获取热门学习视频

```text
GET /api/videos/hot
```

首页未搜索时展示综合评分较高的视频。

## 11.3 搜索推荐

```text
POST /api/recommend
```

请求：

```json
{
  "query": "想学 Python 爬虫",
  "category_id": null,
  "limit": 10,
  "page": 1,
  "weights": {
    "semantic_similarity": 0.3,
    "popularity": 0.1,
    "sentiment": 0.3,
    "comment_quality": 0.3
  },
  "filters": {
    "duration_min": null,
    "duration_max": null,
    "sort_by": "score"
  }
}
```

返回：

```json
{
  "category": {
    "id": "programming",
    "name": "编程开发",
    "confidence": 0.82,
    "level": "high"
  },
  "candidates": [
    {"id": "programming", "name": "编程开发"},
    {"id": "ai_data", "name": "人工智能与数据"}
  ],
  "recommendations": [
    {
      "bvid": "BVxxxxx",
      "title": "Python 爬虫入门",
      "up_name": "某 UP 主",
      "cover_url": "https://...",
      "score": 0.78,
      "detail": {
        "similarity": 0.32,
        "popularity": 0.71,
        "sentiment": 0.55,
        "comment_quality": 0.61
      }
    }
  ]
}
```

`category.level` 取值：

```text
high    高置信度
medium  中置信度
low     低置信度
```

分类确认和权重筛选弹窗均复用该接口，通过 `category_id`、`weights`、`filters` 传递用户选择。

## 11.5 视频详情

```text
GET /api/videos/{bvid}
```

返回 `videos` 表的全部字段，并额外包含 `up_name` 和 `tags`。

### 视频评论

```text
GET /api/videos/{bvid}/comments?cursor=0&limit=20
```

返回该视频的清洗后评论，按 `rpid` 游标分页。

### 视频弹幕

```text
GET /api/videos/{bvid}/danmaku?cursor=0&limit=50
```

返回该视频的清洗后弹幕，按弹幕 `id` 游标分页。

### 视频字幕

```text
GET /api/videos/{bvid}/subtitles
```

返回该视频的全部分段字幕，按分 P 和开始时间排序。

## 11.8 登录注册

```text
POST /api/auth/register
POST /api/auth/login
POST /api/auth/logout
GET  /api/user/profile
```

### 注册

```text
POST /api/auth/register
```

请求：

```json
{
  "username": "zhangsan",
  "password": "abc12345",
  "confirm_password": "abc12345"
}
```

成功返回 `201`：

```json
{
  "message": "注册成功",
  "token": "JWT Token",
  "user": {
    "username": "zhangsan",
    "avatar": "https://example.com/default-avatar.png"
  }
}
```

用户名已存在返回 `409`：

```json
{
  "detail": "用户名已存在"
}
```

### 登录

```text
POST /api/auth/login
```

请求：

```json
{
  "username": "zhangsan",
  "password": "123456"
}
```

成功返回 `200`：

```json
{
  "message": "登录成功",
  "token": "JWT Token",
  "user": {
    "username": "zhangsan"
  }
}
```

用户名或密码错误返回 `400`：

```json
{
  "detail": "用户名或密码错误"
}
```

### 登出

```text
POST /api/auth/logout
```

成功返回 `200`。

### 获取当前用户

```text
GET /api/user/profile
```

成功返回 `200`：

```json
{
  "username": "zhangsan"
}
```

未登录返回 `401`：

```json
{
  "detail": "未登录"
}
```

### 更新用户信息

```text
PUT /api/user/profile
```

请求：

```json
{
  "avatar": "https://example.com/avatar.png"
}
```

成功返回 `200`：

```json
{
  "message": "更新成功",
  "user": {
    "username": "zhangsan",
    "avatar": "https://example.com/avatar.png",
    "created_at": "2026-10-21 10:00:00"
  }
}
```

未登录返回 `401`。
