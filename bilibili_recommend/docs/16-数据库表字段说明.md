# 16 数据库表与字段说明

> 数据库名：`bilibili`
> 字符集：`utf8mb4`
> 排序规则：`utf8mb4_unicode_ci`
> 本文根据当前实际 MySQL 实例中的表结构整理。

## 16.1 维护规范

以后每次新增或修改数据库表，必须同步更新本文，并至少写清：

1. 表的功能和所属模块。
2. 数据来源或生成脚本。
3. 主键、唯一键和普通索引。
4. 每个字段的字段名、类型、约束、默认值和业务含义。
5. 字段中的枚举值、单位或格式说明，例如 `pool` 的取值、时间字段的格式。

新增表后同时检查本文的“表总览”和对应模块的 README/文档链接。

## 16.3 `comments`

保存从爬虫输出导入的原始一级评论。每条记录对应一个评论 ID。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `rpid` | `bigint`，主键 | 评论唯一 ID，用于去重和标识评论 |
| `bvid` | `varchar(32)`，非空 | 评论所属视频的 BV 号 |
| `mid` | `bigint`，默认 `0` | 发表评论的用户 MID |
| `user_name` | `varchar(255)` | 评论用户昵称 |
| `user_level` | `int`，默认 `0` | 用户 B 站等级，通常为 `0` 到 `6` |
| `sex` | `varchar(16)` | 性别，可能为 `男`、`女` 或 `保密` |
| `vip` | `tinyint`，默认 `0` | 是否为当前有效大会员，`1` 是，`0` 否 |
| `message` | `text` | 评论正文 |
| `ctime_text` | `varchar(64)` | 评论发布时间，可读格式 `YYYY-MM-DD HH:MM:SS` |
| `ctime` | `datetime` | 由 `ctime_text` 解析出的评论发布时间 |
| `like_count` | `bigint`，默认 `0` | 评论点赞数 |
| `reply_count` | `bigint`，默认 `0` | 评论下的回复数量，不含子评论正文 |
| `state` | `int`，默认 `0` | 评论状态，`0` 通常表示正常 |
| `ip_location` | `varchar(64)` | 评论 IP 属地，例如“湖北”，不是完整 IP 地址 |
| `image_urls` | `text` | 评论图片 URL，多个地址使用 `|` 分隔 |

索引：主键 `rpid`，普通索引 `idx_bvid(bvid)`。

## 16.4 `comments_clean`

保存清洗、去重后的评论，供分析模块使用。字段结构与 `comments` 完全相同，字段含义见 16.3。

清洗规则：去除空白或无意义文本，过滤广告、链接、加群、兼职等垃圾内容；同一用户的重复评论内容会去重。该表由 `data_cleaning.py` 先建表、清空，再重新生成。

索引：主键 `rpid`，普通索引 `idx_bvid(bvid)`。

## 16.5 `danmaku`

保存从爬虫输出导入的原始弹幕。每条记录对应一个弹幕 ID。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `id` | `bigint`，主键 | 弹幕唯一 ID |
| `bvid` | `varchar(32)`，非空 | 弹幕所属视频的 BV 号 |
| `time_text` | `varchar(32)` | 弹幕在视频中的出现时间，格式 `HH:MM:SS` |
| `time_seconds` | `int`，默认 `0` | 弹幕出现时间换算成的秒数 |
| `weight` | `int`，默认 `1` | 弹幕显示或排序权重 |
| `content` | `text` | 弹幕文字，字幕弹幕可能保存为 JSON 参数 |
| `hash` | `varchar(64)` | 发送用户的匿名 Hash |
| `send_time` | `datetime` | 弹幕发送时间 |
| `pool` | `int`，默认 `0` | 弹幕池，`0` 普通、`1` 字幕、`2` 特殊 |

索引：主键 `id`，普通索引 `idx_bvid(bvid)`，复合索引 `idx_bvid_time(bvid, time_seconds)`。

## 16.6 `danmaku_clean`

保存清洗、去重后的弹幕，供情感分析使用。字段结构与 `danmaku` 完全相同，字段含义见 16.5。

清洗规则：去除空白或无意义文本，过滤广告、链接、加群、兼职等垃圾内容；同一视频内重复的弹幕内容会去重。该表由 `data_cleaning.py` 先建表、清空，再重新生成。

索引：主键 `id`，普通索引 `idx_bvid(bvid)`，复合索引 `idx_bvid_time(bvid, time_seconds)`。

## 16.7 `login_attempts`

保存登录失败次数和锁定状态，用于登录失败次数限制。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `username` | `varchar(20)`，主键 | 尝试登录的用户名 |
| `fail_count` | `int`，默认 `0` | 连续登录失败次数 |
| `locked_until` | `datetime`，可空 | 账号锁定到期时间，`NULL` 表示当前未锁定 |

索引：主键 `username`。

该表由 `auth/database.py` 的 `ensure_tables()` 自动创建，不在 `schema.sql` 中。

## 16.8 `subtitles`

保存视频软字幕或 AI 字幕的每条字幕分段。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `id` | `bigint`，自增主键 | 字幕记录 ID |
| `bvid` | `varchar(32)`，非空 | 字幕所属视频的 BV 号 |
| `cid` | `bigint`，默认 `0` | 当前分 P 的 CID |
| `page` | `int`，默认 `0` | 分 P 序号 |
| `start_time` | `decimal(12,3)`，默认 `0.000` | 字幕开始时间，单位秒 |
| `end_time` | `decimal(12,3)`，默认 `0.000` | 字幕结束时间，单位秒 |
| `content` | `text` | 字幕文本 |

索引：主键 `id`，唯一键 `uk_subtitle(bvid, cid, page, start_time)`，普通索引 `idx_bvid(bvid)`。

## 16.9 `up_info`

保存 UP 主信息。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `mid` | `bigint`，主键 | UP 主用户 MID |
| `up_name` | `varchar(255)` | UP 主昵称 |
| `face_url` | `varchar(512)` | UP 主头像地址 |
| `follower_count` | `bigint`，默认 `0` | UP 主粉丝数 |
| `updated_at` | `datetime`，默认当前时间，更新时自动刷新 | 记录最近更新时间 |

索引：主键 `mid`。

## 16.10 `users`

保存 Web 系统注册用户。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `id` | `bigint`，自增主键 | 用户内部 ID |
| `username` | `varchar(20)`，非空，唯一 | 登录用户名 |
| `password_hash` | `varchar(255)`，非空 | Argon2id 密码哈希，不保存明文密码 |
| `avatar` | `varchar(512)` | 用户头像地址 |
| `created_at` | `datetime`，默认当前时间 | 注册时间 |

索引：主键 `id`，唯一键 `username(username)`。

该表由 `auth/database.py` 的 `ensure_tables()` 自动创建，不在 `schema.sql` 中。

## 16.11 `video_categories`

保存视频与学习方向分类的多对多关系。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `id` | `bigint`，自增主键 | 分类记录 ID |
| `bvid` | `varchar(32)`，非空 | 视频 BV 号 |
| `category_id` | `varchar(64)`，非空 | 学习方向分类 ID，例如 `programming` |
| `score` | `int`，默认 `0` | 该视频在该分类下的匹配得分 |

索引：主键 `id`，唯一键 `uk_bvid_category(bvid, category_id)`，普通索引 `idx_category(category_id)`。

分类 ID 和规则来自 `config/categories.yaml`；没有匹配分类时写入 `other`。

## 16.12 `video_scores`

保存每个视频的分析结果和推荐子分数，由全库分析脚本生成。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `bvid` | `varchar(32)`，主键 | 视频 BV 号 |
| `popularity` | `decimal(8,5)`，可空 | 归一化后的基础热度分，范围约 `0` 到 `1` |
| `sentiment` | `decimal(8,5)`，可空 | 归一化后的弹幕情感得分，范围约 `0` 到 `1` |
| `comment_quality` | `decimal(8,5)`，可空 | 归一化后的评论质量分，范围约 `0` 到 `1` |
| `danmaku_count` | `int`，默认 `0` | 参与分析的清洗后弹幕数量 |
| `comment_count` | `int`，默认 `0` | 参与分析的清洗后评论数量 |
| `subtitle_count` | `int`，默认 `0` | 参与关键词提取的字幕分段数量 |
| `keywords` | `text` | 从字幕提取的关键词，使用逗号分隔 |
| `category_hint` | `varchar(64)` | 根据字幕关键词推测的学习方向 |
| `updated_at` | `datetime`，默认当前时间，更新时自动刷新 | 最近一次分析时间 |

索引：主键 `bvid`。

该表由 `analysis/database_analysis.py` 创建，不在 `schema.sql` 中。

## 16.13 `video_tags`

保存视频标签，一个视频可以有多个标签。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `id` | `bigint`，自增主键 | 标签记录 ID |
| `bvid` | `varchar(32)`，非空 | 视频 BV 号 |
| `tag` | `varchar(255)`，非空 | 标签文本 |

索引：主键 `id`，唯一键 `uk_bvid_tag(bvid, tag)`，普通索引 `idx_tag(tag)`。

## 16.14 `video_texts`

保存每个视频拼接后的文本，供 TF-IDF 相似度计算使用，避免每次实时拼接多张表。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `bvid` | `varchar(32)`，主键 | 视频 BV 号 |
| `video_text` | `text` | 标题、简介、标签和字幕关键词拼接后的文本 |
| `updated_at` | `datetime`，默认当前时间，更新时自动刷新 | 最近生成时间 |

索引：主键 `bvid`。

该表由 `build_video_texts.py` 生成。

## 16.15 `videos`

保存视频核心元数据，是推荐、分类和详情展示的主要数据表。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `bvid` | `varchar(32)`，主键 | B 站视频唯一标识 BV 号 |
| `title` | `text` | 视频标题 |
| `description` | `text` | 视频简介 |
| `mid` | `bigint`，默认 `0` | 视频 UP 主 MID |
| `published_at` | `datetime` | 视频发布时间 |
| `duration_seconds` | `int`，默认 `0` | 视频时长，单位秒 |
| `tid` | `int`，默认 `0` | B 站分区数字 ID |
| `partition_name` | `varchar(64)` | B 站分区名称 |
| `cover_url` | `varchar(512)` | 视频封面 URL |
| `view_count` | `bigint`，默认 `0` | 播放量 |
| `like_count` | `bigint`，默认 `0` | 点赞数 |
| `coin_count` | `bigint`，默认 `0` | 投币数 |
| `favorite_count` | `bigint`，默认 `0` | 收藏数 |
| `share_count` | `bigint`，默认 `0` | 分享数 |
| `reply_count` | `bigint`，默认 `0` | 评论总数，包含子评论 |
| `danmaku_count` | `bigint`，默认 `0` | 弹幕数 |
| `updated_at` | `datetime`，默认当前时间，更新时自动刷新 | 最近导入或更新时间 |

索引：主键 `bvid`，普通索引 `idx_mid(mid)`，普通索引 `idx_partition(partition_name)`。

## 16.16 `favorites`

保存用户收藏的视频，用于“我的收藏”功能。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `id` | `bigint`，自增主键 | 收藏记录 ID |
| `user_id` | `bigint`，非空 | 收藏用户 ID，对应 `users.id` |
| `bvid` | `varchar(32)`，非空 | 收藏的视频 BV 号 |
| `created_at` | `datetime`，默认当前时间 | 收藏时间 |

索引：主键 `id`，唯一键 `uk_user_bvid(user_id, bvid)`，普通索引 `idx_user(user_id)`。

该表由 `auth/database.py` 的 `ensure_tables()` 自动创建，不在 `schema.sql` 中。

## 16.17 `search_history`

保存用户搜索历史，推荐接口会在用户已登录时自动写入。

| 字段 | 类型与约束 | 含义 |
| --- | --- | --- |
| `id` | `bigint`，自增主键 | 历史记录 ID |
| `user_id` | `bigint`，非空 | 搜索用户 ID，对应 `users.id` |
| `keyword` | `varchar(200)` | 用户输入的关键词 |
| `category_id` | `varchar(64)` | 识别出的学习方向分类 ID |
| `created_at` | `datetime`，默认当前时间 | 搜索时间 |

索引：主键 `id`，普通索引 `idx_user(user_id)`。

该表由 `auth/database.py` 的 `ensure_tables()` 自动创建，不在 `schema.sql` 中。
