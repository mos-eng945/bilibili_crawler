# 02 功能需求

## 2.1 用户与角色

| 角色 | 说明 |
| --- | --- |
| 游客 | 未登录用户，只能访问登录和注册页面 |
| 普通用户 | 已登录用户，可以使用搜索、推荐、收藏、历史记录等功能 |

普通用户是本系统的核心使用者。系统第一阶段不设置复杂的权限分级。

## 2.2 系统总体流程

```text
用户登录
   |
   v
输入关键词或标签
   |
   v
识别学习方向
   |
   +-- 高置信度：直接进入推荐
   +-- 中置信度：展示候选大类供用户选择
   +-- 低置信度：进入其他学习、重新输入或选择候选大类
   |
   v
在目标大类下筛选候选视频
   |
   v
计算视频综合推荐分
   |
   v
返回推荐列表
```

## 2.3 用户注册与登录

### 2.3.1 用户注册

- 用户输入用户名和密码完成注册。
- 用户名必须唯一。
- 密码不以明文形式存储，使用安全哈希算法加密后保存。
- 注册成功后自动跳转到登录页或直接登录。

### 2.3.2 用户登录

- 用户输入正确的用户名和密码后登录。
- 登录成功后建立会话，浏览器保存登录状态。
- 登录失败时给出明确提示，不泄露具体是用户名错误还是密码错误。

### 2.3.3 用户登出

- 用户可主动登出，登出后清除登录会话。

### 2.3.4 页面保护

- 推荐、搜索、收藏、历史等页面需要登录后才能访问。
- 未登录访问受保护页面时，自动跳转到登录页。

## 2.4 学习方向识别

系统根据用户输入的内容，判断其所属学习方向。

### 2.4.1 分类方式

系统采用两种方式综合判断：

- 关键词规则匹配：根据预先配置的关键词判断所属大类。
- 文本向量相似度：将用户输入与每个大类的描述进行语义相似度计算。

### 2.4.2 分类置信度

```text
最高类分数 - 第二类分数 > 高阈值   -> 高置信度
最高类分数 >= 低阈值              -> 中置信度
其余情况                         -> 低置信度
```

高置信度时直接采用最高分类结果。中、低置信度时进入交互流程。

## 2.5 分类兜底与交互

### 2.5.1 高置信度

- 直接进入推荐。
- 结果页顶部展示“已识别学习方向：XXX”。
- 提供“方向不对，重新选择”入口。

### 2.5.2 中置信度

- 展示 2 到 3 个候选大类，由用户选择其中一个。
- 用户选择后进入该大类的推荐。

### 2.5.3 低置信度

- 提供以下出口之一：
  - 查看“其他学习”推荐。
  - 更换更具体的关键词重新输入。
  - 从候选大类中选择。
- 不强制用户反复输入。

### 2.5.4 其他学习兜底

- “其他学习”不按大类过滤，在全部视频中进行推荐排序。
- 系统记录低置信度输入，用于后续扩展分类体系。

## 2.6 视频推荐

系统采用两阶段推荐：

```text
第一阶段：确定学习方向
第二阶段：在该方向内根据视频质量排序
```

### 2.6.1 视频综合推荐分

```text
最终推荐分 =
    w1 * 输入与视频的语义相似度
  + w2 * 基础热度分
  + w3 * 弹幕情感得分
  + w4 * 评论质量得分
```

其中权重 `w1` 到 `w4` 在实现阶段通过人工设定或小规模调优确定。

### 2.6.2 基础热度分

基础热度综合考虑：

- 播放量。
- 点赞率。
- 收藏率。
- 投币率。

各项需要归一化到统一范围，避免播放量绝对值过大导致其他指标失效。

### 2.6.3 推荐结果展示

推荐结果至少包含：

- 视频标题。
- 视频链接。
- UP 主名称。
- 所属大类。
- 主要标签。
- 综合评分。
- 情感表现摘要。
- 评论质量摘要。

## 2.7 搜索历史

- 系统记录用户每次搜索的关键词和识别出的学习方向。
- 用户可查看自己的搜索历史。
- 后续可基于搜索历史统计用户偏好大类。

## 2.8 收藏功能

- 用户可以将推荐结果加入收藏。
- 用户可查看和取消收藏。
- 收藏数据用于后续个性化推荐和相似视频召回。

## 2.9 视频数据与分析展示

系统可展示单个视频的分析结果：

- 视频基本信息。
- 弹幕情感分布。
- 弹幕密度变化。
- 评论质量分布。
- 高频关键词。
- 标签一致度风险提示。
