# 08 开发阶段与验收

## 8.1 开发阶段划分

### 第 1 步：环境与项目骨架

- 创建项目目录结构。
- 初始化 Python 虚拟环境。
- 创建 `README.md`、`requirements.txt`。
- 确定第一阶段只做 2 到 3 个大类，例如“编程开发、理工学习、美食烹饪”。

### 第 2 步：小批量爬虫验证

- 写一个最小爬虫。
- 只抓 20 到 50 个视频。
- 抓视频元数据、UP 主信息、部分弹幕和评论。
- 原始数据先保存成 JSON 或 CSV。

### 第 3 步：数据库设计与入库

- 设计视频、弹幕、评论、UP 主等表。
- 写数据入库脚本。
- 使用 `bvid` 去重。
- 保留原始数据表，清洗结果放入清洗表。

### 第 4 步：扩大爬取规模

- 增加限速、随机延迟、重试、断点续传。
- 扩大到几百到几千个视频。
- 实现按视频分页抓取弹幕和评论。

### 第 5 步：数据清洗

- 去重复弹幕、刷屏和无意义内容。
- 过滤纯表情、广告、链接。
- 中文分词、去停用词。
- 写入清洗表。

### 第 6 步：文本分析

- 弹幕情感分析。
- 评论质量评分。
- 标签一致度风险。
- 计算视频综合评分。

### 第 7 步：学习方向分类

- 写分类配置文件。
- 实现关键词规则匹配。
- 实现向量相似度分类。
- 实现高、中、低置信度判断。

### 第 8 步：推荐模块

- 根据输入确定大类。
- 类内使用综合评分排序。
- 输出推荐结果。

### 第 9 步：用户系统与 Web

- 实现注册、登录、登出。
- 实现搜索推荐接口。
- 实现搜索历史和收藏。
- 制作前端页面。
- 使用 ECharts 展示情感和评论分析。

### 第 10 步：联调与验收

- 完整跑通“登录 -> 搜索 -> 分类 -> 推荐 -> 收藏”。
- 检查数据展示是否正确。
- 修复问题和异常情况。

## 8.2 验收标准

系统满足以下条件视为第一版验收通过：

- 能爬取并存储至少一个批次的视频、弹幕和评论数据。
- 用户可注册、登录、登出。
- 用户输入关键词后，系统能识别学习方向。
- 分类不确定时能提供合理的交互选项。
- 系统能返回按综合评分排序的推荐结果。
- 用户能查看搜索历史和收藏视频。
- 系统能展示视频的情感分析和评论质量摘要。
- 本地启动后可通过浏览器正常访问和使用。

## 8.3 当前起步建议

当前最值得做的是：

```text
1. 创建项目目录和虚拟环境
2. 写一个最小爬虫
3. 爬少量视频并打印或保存字段
```

先验证能否稳定获取数据，再继续数据库、分析和推荐模块的开发。
