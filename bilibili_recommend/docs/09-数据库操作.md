
# 09 数据库操作

本文记录 MySQL 数据库的建库、建表、导入数据和查看数据等常用操作。

## 9.1 数据库名称

项目使用数据库名称为：

```text
bilibili
```

该名称定义在：

```text
schema.sql
config.py
```

## 9.2 连接 MySQL

如果 MySQL 已加入 PATH：

```powershell
mysql -u root -p
```

如果未加入 PATH，使用完整路径：

```powershell
& 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' -u root -p
```

输入密码后进入 MySQL 命令行：

```text
mysql>
```

## 9.3 创建数据库和表

进入 `database` 目录：

```powershell
cd C:\course\data\bilibili_recommend\database
```

执行建库建表脚本：

```powershell
Get-Content schema.sql | & 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' -u root -p
```

脚本会创建 `bilibili` 数据库和以下表：

```text
videos
up_info
video_tags
danmaku
comments
subtitles
```

## 9.4 安装 Python 依赖

```powershell
pip install -r requirements.txt
```

主要依赖为 `pymysql`。

## 9.5 导入爬虫数据

在 `database` 目录下执行：

```powershell
python import_all.py
```

脚本默认导入：

```text
C:\course\data\bilibili_crawler\bilibili\output
```

具体文件与表的对应关系：

| output 下的文件 | 导入到的表 |
| --- | --- |
| `search_*.csv`、`videos_*.csv` | videos、up_info、video_tags |
| `video_info.json` | videos、up_info |
| `danmaku_*.csv` | danmaku |
| `comments_*.csv` | comments |
| `subtitle_*.json` | subtitles |

导入脚本可以重复运行，已存在的记录会更新，不会重复插入。

## 9.6 查看数据库

进入 MySQL 命令行后执行：

```sql
SHOW DATABASES;
```

选择项目数据库：

```sql
USE bilibili;
```

查看所有表：

```sql
SHOW TABLES;
```

## 9.7 查看表结构

```sql
DESCRIBE videos;
```

或者：

```sql
SHOW COLUMNS FROM videos;
```

## 9.8 查看表数据

查看前 10 条视频：

```sql
SELECT * FROM videos LIMIT 10;
```

查看前 20 条弹幕：

```sql
SELECT * FROM danmaku LIMIT 20;
```

查看前 20 条评论：

```sql
SELECT * FROM comments LIMIT 20;
```

查看前 20 条字幕：

```sql
SELECT * FROM subtitles LIMIT 20;
```

## 9.9 按条件查询

查看某个视频的所有评论：

```sql
SELECT * FROM comments
WHERE bvid = 'BV1G9aU6VEiq'
LIMIT 20;
```

统计某个视频的弹幕数量：

```sql
SELECT COUNT(*) FROM danmaku
WHERE bvid = 'BV1G9aU6VEiq';
```

## 9.10 使用 MySQL Workbench 查看

打开 MySQL Workbench，连接参数：

```text
Hostname: 127.0.0.1
Port: 3306
Username: root
Password: 你的 root 密码
```

连接后：

- 左侧 `Schemas` 展开 `bilibili`。
- 展开 `Tables` 查看所有表。
- 右键表选择 `Select Rows - Limit 1000` 查看数据。
